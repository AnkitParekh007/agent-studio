# Code of Conduct

Agent Studio uses a simple professional contribution standard.

## Expected behavior

- be respectful, specific and constructive
- critique code and architecture rather than people
- explain tradeoffs when proposing substantial changes
- respect privacy, credentials and security-sensitive information
- avoid deceptive capability claims or fabricated adoption/performance metrics
- prefer reproducible evidence when reporting bugs

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, publishing private information, credential disclosure, spam, or intentionally misleading technical claims are not acceptable.

## Maintainer response

Maintainers may edit, hide or remove content and restrict participation when necessary to protect contributors, users or project integrity.
