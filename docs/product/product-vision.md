# Product vision

Agent Studio enables organizations to create an AI agent once, govern it centrally, and publish it as a secure web application, desktop application, embedded copilot, or API.

## Principles

1. **Define once** — one governed agent identity with immutable versioned configuration.
2. **Govern centrally** — approval workflows, RBAC, audit, budgets, and org isolation.
3. **Publish anywhere** — hosted web, embed, desktop shell, and secured API/SDK.
4. **Provider-neutral core** — Claude Managed Agents first; all runtime I/O through adapters.
5. **Secure by default** — clients never receive provider keys or server secrets.

## MVP outcome

An organization can create an agent, configure instructions, submit for approval, approve a version, provision a deployment through a runtime adapter, publish a hosted web app, and run a streamed session through the Agent Gateway with audit and usage persistence.
